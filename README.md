# 無線電追蹤三角定位工具

一款專為野外無線電追蹤設計的瀏覽器 GIS 工具。  
在地圖上輸入多個觀測站的座標與方位角，系統自動計算目標位置並視覺化顯示方位線與交會點。

🔗 **線上使用**：https://win-hs.github.io/triangulation/

---

## 功能特色

- 🗺 互動式地圖（OpenStreetMap / 地形圖 / 衛星影像可切換）
- 📡 支援 2 站以上三角定位，顯示所有方位線與交會點
- 🧭 真北 / 磁北一鍵切換，使用 WMM2025 模型自動換算磁偏角
- 📅 可指定日期，確保磁偏角精度（有效期至 2029 年）
- 📌 地圖點選或手動輸入觀測站座標（支援緯,經 / 經,緯 兩種順序）
- 📐 兩種交會算法：平面法 / 測地線法（大圓交會）
- 📊 兩種目標估算器：Centroid 平均法 / MLE 最大概似估計
- ⚠️ 自動警示夾角過小（＜30°）導致的定位誤差風險

---

## 使用方法

### 1. 新增觀測站

**手動輸入**
1. 按「＋ 手動新增」
2. 輸入座標（依選定順序，如 `24.0, 120.5`）
3. 輸入方位角（0–360°）
4. 按「確認」

**地圖點選**
1. 按「＋ 地圖點選」
2. 在地圖上點選觀測站位置
3. 在彈出視窗輸入方位角，按「確認」

### 2. 讀取結果

新增 2 個以上觀測站後，系統自動計算：
- **目標座標**：估算的信號來源位置
- **最小銳角**：所有方位線配對中最小的交會角，越大定位越準確
- 點「展開全部夾角」查看每對觀測站的夾角

### 3. 調整設定

詳見下方各選項說明。

## 選項說明

### 北向：真北 / 磁北

| | 說明 | 適用情況 |
|---|---|---|
| **真北** | 以地圖正北為基準 | 使用地形圖、GPS 標示方位時 |
| **磁北** | 以羅盤指針為基準 | 使用指北針直接量測方位角時 |

選擇「磁北」時需設定觀測日期，系統依 **WMM2025 地磁模型**自動換算磁偏角（台灣地區約 −4° 至 −5°），並在按鈕旁顯示當前偏差值。

> ⚠️ 台灣地區磁偏角約 −4.6°（2025 年），若使用磁北但未修正，定位結果會有系統性偏移。

---

### 座標輸入順序：緯,經 / 經,緯

| | 格式範例 | 說明 |
|---|---|---|
| **緯,經** | `24.0, 120.5` | 台灣地區常用格式，Google Maps 預設 |
| **經,緯** | `120.5, 24.0` | 部分 GPS 設備、GIS 軟體的輸出格式 |

切換後，現有觀測站的座標顯示會同步更新。

---

### 交會算法：平面 / Geodesic

| | 原理 | 適用距離 | 速度 |
|---|---|---|---|
| **平面** | 將緯經視為 XY 直角座標計算 | ＜100 km 誤差可接受 | 快 |
| **Geodesic** | 球面大圓交會（嚴格幾何） | 任意距離均準確 | 略慢 |

台灣野外作業觀測距離通常在 10–50 km 以內，**平面法**即可滿足精度需求。跨縣市長距離追蹤建議改用 Geodesic。

---

### 估算器：Centroid / MLE

當觀測站超過 2 個時，各對方位線的交點不會完全重合（因量測誤差），需從多個交點估算最終目標位置。

| | 原理 | 特點 |
|---|---|---|
| **Centroid** | 所有交點的算術平均 | 計算簡單、結果直觀，但可能受離群交點影響 |
| **MLE** | 迭代加權最小平方法（Lenth 1981）| 對誤差較大的方位線降低權重，精度較高 |

建議預設使用 **Centroid** 先觀察交點分布，若各交點離散程度大則改用 **MLE**。

---

### 最小銳角警示

兩條方位線的交會角越大，定位越穩定；越小，誤差越敏感。

| 最小銳角 | 狀態 |
|---|---|
| ≥ 30° | 正常 |
| ＜ 30° | ⚠️ 警示，定位誤差可能急遽放大 |

**理想配置**：觀測站盡量分散在目標周圍不同方向，使各對夾角接近 60°–90°。

## 底圖切換

右上角圖層按鈕可切換三種底圖：

| 底圖 | 用途 |
|---|---|
| OpenStreetMap | 一般道路地圖（預設） |
| OpenTopoMap | 等高線地形圖（野外作業推薦） |
| Esri Imagery | 衛星空拍影像 |

## 技術規格

- **純前端**：HTML / CSS / JavaScript，無伺服器需求
- **地圖**：Leaflet.js 1.9.4
- **地磁模型**：WMM2025（有效期 2025–2030 年），自行托管，離線可用
- **測地計算**：Turf.js 6.5.0
- **無框架**：無需 Node.js / 編譯，可直接在瀏覽器開啟
